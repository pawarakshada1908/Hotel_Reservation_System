# Hotel Reservation System

## Project Description
The Hotel Reservation System is a Java-based application designed to manage hotel room reservations.

It helps users handle hotel booking operations in a simple and organized way.

## Technologies Used
- Java
- Eclipse IDE

## Features
- Hotel room reservation management
- Booking-related operations
- User-friendly program execution

## How to Run
1. Download or clone this repository.
2. Open the project in Eclipse IDE.
3. Compile and run `HotelReservationSystem.java`.
